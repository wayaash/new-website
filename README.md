# yashuuu.in

Minimal multi-page personal website made with plain HTML, CSS and vanilla JavaScript.

## Run
Open `index.html` in a browser. No build tools are required.

## Pages
- `index.html` — home
- `experience.html` — experience and community involvement
- `gallery.html` — image gallery with filters and lightbox
- `contact.html` — email contact only

## Before publishing
- Replace sample gallery images with your own photos if desired.
- Confirm the experience descriptions and dates are accurate.
- Update the email address if needed.
